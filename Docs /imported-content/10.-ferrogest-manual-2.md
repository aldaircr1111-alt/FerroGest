## 1. Introducción

### Propósito de este manual

En este manual explicamos de forma práctica y paso a paso cómo manejar **FerroGest**, la aplicación web que desarrollamos para llevar el control del inventario, registrar las ventas en mostrador, administrar clientes y usuarios, y revisar los indicadores principales de la ferretería.

La idea al escribir este documento es que cualquier persona del negocio pueda empezar a usar el sistema desde el primer día sin necesidad de saber de programación ni de sistemas. Por eso, en cada módulo indicamos qué pantalla abrir, en qué botón dar clic y qué resultado debería verse en pantalla.

### Alcance

Esta guía corresponde a la versión 1.0 de FerroGest y abarca todos los módulos habilitados para los tres roles que maneja la aplicación:

* Inicio y cierre de sesión.
* Dashboard con indicadores que cambian según el perfil de quien ingresa.
* Módulo de ventas (catálogo, armado del ticket, asignación de cliente, descuentos, medios de pago y comprobante).
* Módulo de inventario (registro de productos, entradas de mercancía, alertas de stock mínimo y activación o desactivación de referencias).
* Módulo de clientes (registro, búsqueda, estado y consulta del historial de compras para el administrador).
* Historial de ventas (búsqueda, revisión de tickets y anulación).
* Gestión de usuarios y roles (creación, edición y desactivación de cuentas).
* Asistente inteligente para hacer consultas rápidas sobre stock, precios y ventas.

Aquí no incluimos pasos de instalación del servidor, configuración de la base de datos ni mantenimiento del código, porque toda esa parte técnica ya está documentada aparte en los archivos técnicos del proyecto.

### ¿A quién está dirigido?

## 2. Descripción general de FerroGest

### ¿Qué es FerroGest?

FerroGest es una aplicación web pensada para el trabajo diario de una ferretería. Reúne en un mismo sistema el control de las existencias en bodega, el registro de ventas en mostrador con facturación simulada, la base de datos de clientes y el manejo de las cuentas de los empleados.

El eje del sistema es el inventario. Cada vez que entra mercancía nueva, se hace una venta o se anula un comprobante, el sistema genera un movimiento que actualiza las cantidades disponibles y guarda el registro de quién realizó la acción, en qué momento y por qué. De esta manera, el stock que aparece en pantalla siempre concuerda con lo que realmente se ha movido.

### Módulos del sistema

| Módulo                | Función principal                                                                                         | Acceso                                   |
| --------------------- | --------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| Dashboard             | Presenta los indicadores clave del negocio o del almacén según el rol.                                    | Todos los roles                          |
| Ventas                | Permite armar una venta en mostrador y generar el comprobante.                                            | Administrador y vendedor                 |
| Inventario            | Sirve para crear productos, registrar entradas y vigilar los niveles de stock.                            | Administrador y encargado del inventario |
| Clientes              | Permite guardar y consultar clientes; ver el historial completo de compras es solo para el administrador. | Administrador y vendedor                 |
| Historial de ventas   | Permite buscar comprobantes, revisar su detalle y anular ventas (solo administrador).                     | Administrador y vendedor                 |
| Usuarios              | Sirve para crear cuentas del personal, asignar roles y controlar permisos.                                | Únicamente administrador                 |
| Asistente inteligente | Responde preguntas sobre existencias, precios y ventas en lenguaje normal.                                | Su alcance depende del rol               |

### Relación de los módulos entre sí

En FerroGest ningún módulo trabaja de forma separada. Cuando se realiza una venta, las unidades vendidas se descuentan automáticamente del inventario y el ticket queda guardado en el historial de ventas. Si el encargado del inventario registra una entrada de mercancía, aumentan las existencias y las tarjetas del Dashboard se actualizan solas. De igual manera, cualquier cliente guardado puede asociarse a una venta y luego revisarse desde el módulo de Clientes. Por eso, si alguna cifra no parece correcta, lo más práctico es revisar todo el ciclo: el producto, el inventario, la venta y el comprobante.

## 3. Roles y permisos

El sistema trabaja con tres perfiles distintos. El rol se asigna al momento de crear la cuenta del empleado y define tanto las opciones que se ven en el menú como lo que el servidor le permite ejecutar.

| Rol                      | Área de trabajo                                      | Acciones permitidas                                                                                                                                                          |
| ------------------------ | ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Administrador            | Controla de manera general toda la ferretería        | Tiene acceso a todo lo que hace tanto el vendedor como el encargado del inventario, además de poder anular ventas, consultar los costos de compra y administrar los usuarios |
| Vendedor                 | Se encarga de la atención y el cobro en el mostrador | Registra ventas, consulta el catálogo, administra los datos de los clientes y revisa el historial de comprobantes.                                                           |
| Encargado del inventario | Control de la bodega y la mercancía                  | Crea y edita los productos, registra las entradas de mercancía y controla las alertas de stock bajo.                                                                         |

### Matriz de acceso por módulo

| Módulo               | Administrador | Vendedor        | Encargado |
| -------------------- | ------------- | --------------- | --------- |
| Dashboard            | Sí            | Sí              | Sí        |
| Ventas               | Sí            | Sí              | No        |
| Inventario           | Sí            | No              | Sí        |
| Clientes             | Sí            | Sí              | No        |
| Historial de ventas  | Sí            | Sí (sin anular) | No        |
| Usuarios             | Sí            | No              | No        |
| Ver costos de compra | Sí            | No              | No        |
| Anular una venta     | Sí            | No              | No        |

Los permisos tienen una doble validación. Por un lado, la interfaz oculta los módulos y botones que no le corresponden al usuario; por otro, el servidor también rechaza cualquier solicitud que no esté autorizada. Así, incluso si alguien intenta escribir una ruta directamente en el navegador, no podrá hacer nada fuera de su rol. Como buena práctica de seguridad, siempre conviene asignar únicamente el rol que cada empleado necesita para su puesto: un vendedor no necesita entrar a modificar el inventario y un encargado de bodega no tiene por qué anular ventas.

* Evita prestar tu usuario: absolutamente todos los movimientos quedan registrados con el nombre de la cuenta que los hizo.

## 5. Navegación general

### Barra lateral de módulos

Todas las pantallas de FerroGest comparten la misma estructura para que sea fácil ubicarse. Al lado izquierdo está la barra lateral, dividida en dos bloques: **Operaciones** (Dashboard, Ventas, Inventario, Clientes e Historial de Ventas) y **Configuración** (Usuarios). Ahí solo vas a ver los módulos que tu rol tiene habilitados, y la sección en la que te encuentras aparece resaltada con un tono más claro.

### Encabezado y datos del usuario

En la parte superior verás la ruta de ubicación actual, por ejemplo, "Ferretería Central › Panel de Operaciones", junto con tu nombre, tu rol y el botón para cerrar sesión. Esa ruta superior es útil para confirmar rápidamente en qué pantalla estás parado.

### Acceso al asistente inteligente

En la esquina inferior izquierda aparece un botón flotante con el ícono de un robot. Al abrirlo puedes hacer preguntas en lenguaje natural sobre existencias, precios o ventas; su uso completo se detalla en la sección 12.

## 6. Dashboard

El Dashboard es la primera pantalla que ves al iniciar sesión. Ofrece un panorama rápido de cómo va la ferretería y su contenido se adapta a tu perfil: el administrador revisa las cifras globales de ventas y dinero, el vendedor consulta únicamente su propio rendimiento y el encargado del inventario ve el estado del almacén.

### Panel del administrador

| Indicador                     | Información que se muestra                                                         |
| ----------------------------- | ---------------------------------------------------------------------------------- |
| Ventas del día (hoy)          | Total vendido durante la fecha actual, excluyendo comprobantes anulados.           |
| Ventas del mes                | Dinero acumulado en lo que va del mes en curso.                                    |
| Stock bajo y crítico          | Cantidad de productos activos que ya llegaron a su mínimo o están por debajo       |
| Total                         | Suma total de las ventas correspondientes al periodo que tengas seleccionado       |
| Ticket promedio               | Valor promedio de cada venta en el periodo elegido.                                |
| Comprobantes anulados         | Número de ventas que fueron anuladas durante ese periodo.                          |
| Efectivo vs digitales         | Comparativa entre lo pagado en efectivo y lo recibido por tarjeta o transferencia. |
| Personas naturales / Empresas | Cantidad de clientes registrados divididos por tipo.                               |
| Top 5                         | Los cinco productos que más ingresos han generado en el periodo.                   |

### Panel del vendedor

En esta vista el vendedor solo ve los resultados de su propio trabajo: **Mis ventas del día**, **Mis ventas del mes**, **Mis tickets del periodo** y el total que ha vendido. Los comprobantes anulados que aparecen allí también son únicamente los suyos, lo que le permite cuadrar su caja sin cruzarse con la información de otros cajeros.

### Panel del encargado del inventario

El encargado de bodega no visualiza montos de dinero. Su tablero está enfocado completamente en las existencias: referencias en stock bajo o crítico, productos agotados, artículos activos y desactivados, entradas registradas en el día y últimos movimientos. La tabla **Productos más críticos** funciona prácticamente como una lista de prioridades para saber qué referencias toca reponer primero.

## 7. Módulo de ventas

El módulo de Ventas corresponde al punto de venta del mostrador. Desde aquí puedes buscar productos en el catálogo, ir armando el ticket del cliente, aplicar un descuento si corresponde, seleccionar el medio de pago y emitir el comprobante. En cuanto confirmas la venta, el sistema descuenta automáticamente las unidades del inventario y guarda la transacción en el historial.

### Antes de empezar

* Revisa que ya hayas iniciado sesión con tu cuenta y que tanto el lector de códigos como la impresora estén conectados, si los utilizas.
* Si el cliente va a pedir facturación a nombre de una empresa, ten a la mano su NIT y demás datos.
* Confirma bien la forma de pago antes de cerrar la venta, ya que una vez confirmada queda registrada al instante y solo un administrador podría anularla.

### Explorar el catálogo

El catálogo muestra únicamente los productos activos junto con su código SKU, nombre, especificación, categoría, existencias disponibles y precio unitario con IVA incluido. Se listan diez artículos por página y en la parte inferior se indica el total de referencias encontradas.

Notarás que en la columna de stock aparece el texto _"Ubicación por definir"_ en todas las filas. Esto ocurre porque en esta versión todavía no se guarda la ubicación física de cada estantería en bodega, pero no afecta en nada el proceso de venta.

* Para sacar un artículo del ticket, da clic en la **X** ubicada en la esquina superior derecha de ese producto.

En el comprobante verás el cliente, el medio de pago, el total liquidado y el cambio si se pagó en efectivo. Para atender a la siguiente persona, da clic en **Nueva venta**; eso limpia el ticket y vuelve a dejar seleccionado a _Consumidor Final_.

### Reglas importantes del módulo de ventas

* Las existencias se descuentan en el momento exacto en que se confirma la operación.
* El sistema nunca deja vender más unidades de las que hay en inventario.
* Si dos cajeros intentan vender las últimas unidades del mismo producto al mismo tiempo, el servidor bloquea temporalmente el registro mientras actualiza el stock; si ya no alcanza para ambos, una de las dos ventas será rechazada por falta de existencias.
* Cada ticket recibe un consecutivo único con el formato TK-AAAA-00000.
* Internamente los precios se guardan sin IVA, pero tanto en el catálogo como en el ticket se muestran ya con el impuesto incluido.

### Errores frecuentes en Ventas

| Mensaje o situación                   | Cómo solucionarlo                                                                               |
| ------------------------------------- | ----------------------------------------------------------------------------------------------- |
| “No tiene stock disponible”           | El artículo ya está en cero; revisa en inventario si llegó mercancía o sugiere otra referencia. |
| Aparece “Faltan” al escribir el monto | El valor que digitaste es menor al total de la venta; corrígelo o deja la casilla vacía.        |
| El botón Confirmar está deshabilitado | Todavía no has agregado productos al ticket o el monto recibido es menor al total.              |
| Un producto no aparece en el catálogo | Puede estar desactivado, agotado o bajo otra categoría distinta a la que filtraste.             |

## 8. Módulo de inventario

Desde el módulo de Inventario se maneja todo lo relacionado con la bodega: creación de productos, registro de entradas de mercancía, definición de mínimos y activación o desactivación de referencias.

### Descripción del panel

Los productos se presentan en una tabla de hasta ocho registros por página, indicando código, nombre, categoría, unidad de medida, precio de venta con IVA, tarifa de IVA, stock actual con su mínimo, estado y botones de acción. En la parte inferior hay cuatro tarjetas de resumen: total de referencias, artículos activos, productos bajo stock mínimo y desactivados. Ese bloque inferior solo se muestra cuando ingresas con perfil de administrador.

## 12. Asistente inteligente

El asistente inteligente permite hacer preguntas en lenguaje cotidiano sobre la información del negocio. Funciona únicamente en modo de consulta, solo lectura, así que no modifica precios, ni borra datos, ni descuenta inventario.

### Cómo abrir el asistente

* Estando en el Dashboard, haz clic en el botón flotante con el ícono de robot en la esquina inferior izquierda.
* Escribe tu pregunta en la barra inferior y dale clic al botón de enviar.
* Si prefieres algo más rápido, puedes dar clic directamente en alguna de las preguntas sugeridas que salen encima del cuadro de texto.

### Qué puede consultar según el rol

| Tipo de consulta                 | Administrador | Vendedor | Encargado inventario |

| Ventas del día                   | Sí            | No       | No                   |
| Productos más vendidos           | Sí            | No       | No                   |
| Ventas por vendedor              | Sí            | No       | No                   |

### Recomendaciones y límites de uso

* Cuanto más directa sea la pregunta, mejor responde: es preferible escribir "¿cuántos bombillos LED quedan?" en lugar de algo muy abierto como "háblame del inventario".
* Cada pregunta tiene un máximo de 500 caracteres.
* Existe un límite de 15 consultas por minuto por usuario y un tiempo máximo de espera de 30 segundos por respuesta.
* Si el servicio de inteligencia artificial no está configurado en el servidor, el asistente no responderá; en la sección de solución de problemas se indica qué hacer.

<details>

<summary>¿Se puede usar FerroGest desde el celular?</summary>

La aplicación fue pensada para trabajar en computador. En una tablet se puede abrir, pero varias tablas van a pedir desplazamiento horizontal. Para trabajar cómodo en el mostrador lo ideal es un computador de escritorio con resolución de 1600 × 900.

<details>

Por el momento, el cambio lo realiza directamente el administrador desde el módulo de Usuarios. Solo debes avisarle para que te asigne la nueva clave y entrar con ella en tu siguiente turno.

</details>

<details>

<summary>¿Por qué no me aparece el módulo de Inventario en el menú?</summary>

Porque el rol asignado a tu cuenta no tiene permiso para entrar allí. La barra lateral solo muestra las secciones habilitadas para tu perfil.

</details>

<details>

<summary>¿Por qué el botón "Agregar" aparece bloqueado en un producto?</summary>

Porque ese producto no tiene existencias disponibles. Verás la fila en gris con la etiqueta _"Agotado"_, y solo se volverá a habilitar cuando se registre una entrada de mercancía.

</details>

<details>

<summary>¿Puedo hacer una venta sin pedirle datos al cliente?</summary>

Sí. Si no seleccionas ningún cliente, el ticket sale automáticamente a nombre de **Consumidor Final** con la cédula 222222222222.

</details>

<details>

<summary>¿Cómo arreglo una venta que quedó mal registrada?</summary>

Tienes que pedirle al administrador que la anule desde el Historial de Ventas indicando el motivo, y luego volver a registrar la venta con los datos correctos.

</details>

<details>

<summary>¿Por qué busco un producto en Ventas y no aparece?</summary>

Puede que esté desactivado, sin existencias o en una categoría diferente a la que tienes filtrada. Conviene revisarlo en Inventario.

</details>

<details>

<summary>¿Se pueden borrar productos, clientes o usuarios definitivamente?</summary>

No. Para no perder el rastro de las operaciones, trazabilidad, el sistema solo permite desactivarlos y conserva todo su historial.

</details>

<details>

<summary>¿Cómo se genera el número de ticket?</summary>

Lo asigna automáticamente el sistema con un consecutivo único que sigue el formato TK-AAAA-00000.

</details>

<details>

<summary>¿Los precios que aparecen en pantalla ya tienen IVA?</summary>

En la base de datos los precios se guardan sin IVA, pero en el catálogo de mostrador y en el ticket ya se muestran con el impuesto incluido.

</details>

<details>

<summary>¿Qué pasa si dos cajeros intentan vender la última unidad al mismo tiempo?</summary>

El servidor bloquea el producto por un instante mientras verifica el stock real, así que una de las dos ventas se confirmará y la otra será rechazada por falta de existencias.

</details>

<details>

<summary>¿Se puede reactivar una venta que ya fue anulada?</summary>

No. La anulación no tiene marcha atrás; si el cliente decide llevar los artículos de nuevo, hay que registrar una venta nueva.

</details>

## 15. Buenas prácticas de operación

### Al empezar el turno

* Inicia sesión únicamente con tu propia cuenta y verifica en la esquina superior derecha que aparezca tu rol correcto.
* Échale un vistazo al Dashboard para ver cómo están las ventas del día, las alertas de stock bajo y los comprobantes.
* Si trabajas con lector de código de barras o impresora, verifica que estén respondiendo bien antes de atender al primer cliente.

### Durante el día

* Confirma siempre el medio de pago antes de dar clic en **Confirmar venta**.
* Cuando te paguen en efectivo, apóyate en el campo **Monto recibido** para evitar errores dando vueltas.
* Registra las entradas de mercancía apenas lleguen a la ferretería y no las dejes acumuladas para el final del día.
* Si no estás seguro de si un cliente ya está en el sistema, búscalo primero por su número de documento antes de crearlo de nuevo.

### Al terminar el turno

* Revisa el historial del día para verificar que todos los tickets hayan quedado bien registrados.
* Infórmale al administrador si hubo alguna venta que requiera anulación.
* Cierra siempre tu sesión antes de retirarte, sobre todo si varias personas usan el mismo computador.

### Errores comunes que terminan generando descuadres

* Confirmar ventas sin verificar si el cliente pagó en efectivo, tarjeta o transferencia, porque después la caja no cuadra con el sistema.
* Pedir anulaciones solo para "arreglar" un precio mal cobrado sin revisar antes, ya que toda anulación es permanente y queda registrada con su motivo.
* Intentar llevar cuentas de stock de memoria en lugar de registrar cada entrada, venta o ajuste en FerroGest.

En general, cuando haya alguna duda con un cobro o una cantidad, es mejor frenar un segundo y preguntar antes de confirmar, porque corregir un error a tiempo siempre es mucho más sencillo que buscar un descuadre al final del mes.

## Anexo B. Formas de pago y estados de una venta

| Forma de pago | Cuándo seleccionarla                                              | Particularidades de este método de pago                    |
| ------------- | ----------------------------------------------------------------- | ---------------------------------------------------------- |
| Efectivo      | Cuando el cliente paga en la caja con billetes o monedas.         | Permite digitar el monto recibido para calcular el cambio. |
| Tarjeta       | Cuando el pago se hace con tarjeta débito o crédito por datáfono. | No pide monto recibido                                     |
| Transferencia | Cuando se paga por transferencia bancaria o billetera digital.    | No pide monto recibido                                     |

### Estados de una venta

| Estado  | Qué indica                                  | Qué sucede en el inventario                         |
| ------- | ------------------------------------------- | --------------------------------------------------- |
| Activa  | Venta válida y vigente                      | Las unidades vendidas siguen descontadas del stock  |
| Anulada | Venta anulada por parte de un administrador | Las unidades regresan automáticamente al inventario |
